# 🏪 Souk Online

Plateforme d'achat/vente algérienne - Style Ouedkniss

## Fonctionnalités
- Poster une annonce (titre, description, prix, image)
- Chercher et filtrer par catégorie, wilaya, prix
- Toutes les 48 wilayas d'Algérie
- 12 catégories variées
- Upload d'images directement
- Sauvegarde automatique

## Comment utiliser
1. Ouvre `souk-online.html` dans un navigateur
2. Clique sur "Poster" pour ajouter une annonce
3. Clique sur une annonce pour voir les détails
4. Les annonces se sauvegardent automatiquement
